# North Star Bakery — Touchstone 3

## Project Overview
This project involves developing the website for Client A, a product-focused neighborhood bakery. 
The website’s primary objective is to introduce customers to North Star Bakery, showcase its products, 
provide business information, and facilitate customer inquiries and pre-order requests.

## Touchstone 3: Styling with CSS

In Touchstone 3, we focused on enhancing the website’s visual appeal, layout, and responsiveness using 
CSS. While retaining the original HTML structure from the previous Touchstone, we introduced an external 
stylesheet to create a more polished and consistent design across the website.

## Changes Made for Touchstone 3

For this Touchstone, I made the following changes:

- External CSS Stylesheet: I created and linked an external CSS stylesheet to the website.
- Warm Color Palette: I developed a warm color palette that aligns with the bakery’s handmade and welcoming brand.
- Navigation Bar and Logo: I styled the navigation bar and positioned the North Star Bakery logo within
  the navigation/header area. I also adjusted the bakery logo to ensure it remains visible against the navigation bar background.
- Page Elements Styling: I styled headings, paragraphs, buttons, forms, images, and other page elements to enhance readability.
- Flexbox for Layout: I utilized Flexbox to improve the page layout and alignment.
- Spacing, Borders, and Visual Styling: I added spacing, borders, and other visual styling elements to improve the overall appearance of the website.
- Responsive CSS: I incorporated responsive CSS with a media query to ensure the website adapts to smaller screens.
- Consistent Styling: I maintained consistent styling across the Home, Products, About, and Contact pages.
